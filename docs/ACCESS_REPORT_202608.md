
### 📖 用語の定義と指標の関係性について
自治体・行政報告における指標の定義は以下の通りです。常に **「PV数 ≧ セッション数 ≧ ユニークユーザー（UU）」** の関係が成り立ちます。

* **ページビュー（PV）**：ユーザーがページを閲覧した**「延べ回数」**。1回の訪問で3ページ閲覧した場合は「3 PV」とカウントされます。
* **セッション数（訪問数）**：ユーザーがサイトを訪れてから離脱するまでの**「一連の訪問回数」**。同じ人が午前と午後に2回訪問した場合は「2 セッション」となります。
* **ユニークユーザー（UU / 訪問者数）**：期間中にサイトを訪れた**「固有の人数」**。同じ人が月に何度訪問しても「1 UU」としてカウントされます。

1. **8月度実績（月間1,048PV）**:

2. **大都市圏（東京都・大阪府・愛知県・神奈川県）が全体の約65%**:
   * 長野県内（35.3%）の閲覧に加え、**東京都（26.6%）をはじめとする首都圏・関西圏・中京圏からのアクセスが約65%**を占めています。
3. **高い記事精読率と町内事業者・公式SNSへの力強い送客実績**:
   * 平均滞在時間は2分24秒、詳細閲覧回数は累計1,241回に達し、公式SNSや直売所・町内農園・飲食店・EC等の外部サイトへ**累計328件の送客・アクション**を創出いたしました。
