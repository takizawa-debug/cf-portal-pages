3. **高い記事精読率と地域事業者・SNSへの確実な送客**:
   * 平均滞在時間は2分24秒、詳細閲覧回数は累計1,241回に達し、公式SNSや直売所・飲食店等の外部サイトへ**累計119件の送客・アクション**を創出いたしました。
