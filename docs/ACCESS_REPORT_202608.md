## 1. エグゼクティブサマリー（全体総括）

飯綱町の観光・農業・食の魅力を多言語（日本語・英語・中国語）で国内外へ発信する公式ポータルサイト「**りんごのまち いいづな（Appletown Iizuna）**」における、2026年2月15日の計測開始から2026年8月31日までのアクセス解析結果を報告いたします。

```
【期間全体（2026年2月〜8月）の主要実績ハイライト】
・累計ページビュー（PV）   : 4,485 PV
・累計セッション数          : 3,439 セッション
・累計ユニークユーザー（UU） : 1,438 人
・平均滞在時間              : 約 2 分 24 秒（記事精読率が極めて高い）
・詳細モーダル開封数        : 1,249 回（セッションあたり約 36.3%）
```

### 🌟 主要な成果とトレンド
1. **8月度における「月間1,000PV（1,048PV）」の達成**:
   * 2月の立ち上げ（157PV）から右肩上がりに成長を続け、**8月度には月間1,048PV・850セッションを記録**いたしました。
2. **大都市圏（東京都・大阪府・愛知県・神奈川県）が全体の約70%**:
   * 長野県内（約30%）のみならず、**首都圏や関西・中京圏などの消費地・観光潜在層へダイレクトに情報が到達**しています。
3. **深いエンゲージメント（平均滞在時間 2分超 / モーダル閲覧1,200回超）**:
   * 一般的な自治体・観光サイトの平均滞在時間（30〜45秒）を大幅に上回り、**1分〜4分超の深い滞在時間**を維持。品種ごとの詳細や生産者の想いがじっくり読まれています。

## 7. 今後の示唆とプロモーション提言

1. **秋の86日間 りんごフェア（9月〜11月）での爆発的集客**:
   * 9月より開始される「いいづな英国りんごフェア」「いいづなりんごスイーツフェア」と連動し、トップページの注目バナーおよび公式Instagram（@iizuna_ringofair_official）からの誘導を強化することで、**秋期は月間 3,000〜5,000 PV規模への飛躍**を目指します。
2. **三つ折りチラシ（QRコード）とのリアル連携**:
   * チラシ・ポスターの配布に伴い、紙媒体から直接個別記事や品種詳細へ遷移するQR導線を活用し、現地来訪者の周遊率と購買率を向上させます。
3. **多言語発信（インバウンド）の継続**:
   * 希少品種ブラムリーやスイーツコンクールの情報を英語・中国語で発信し、海外観光客および在日外国人コミュニティへの訴求を継続推進いたします。
