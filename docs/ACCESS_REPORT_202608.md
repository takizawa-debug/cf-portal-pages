**対象期間：2026年2月15日 〜 2026年8月31日（日本時間）**  
**発行元：飯綱町多言語アップルプロジェクト事務局**

---

## 1. 全体総括（主要実績）

飯綱町の観光・農業・食の魅力を多言語（日本語・英語・中国語）で国内外へ発信する公式ポータルサイト「**りんごのまち いいづな（Appletown Iizuna）**」における、2026年2月15日から2026年8月31日までのアクセス解析実績です。

```
【期間全体（2026年2月〜8月）の主要実績】
・累計ページビュー（PV）   : 4,485 PV
・累計セッション数          : 3,439 セッション
・累計ユニークユーザー（UU） : 1,438 人
・平均滞在時間              : 約 2 分 24 秒
・詳細モーダル閲覧数        : 1,241 回
```

### 📌 主要な成果
1. **8月度における月間1,000PV（1,048PV）の達成**:
   * 2月の運用開始（157PV）以降、順調に推移を伸ばし、**8月度には月間1,048PV・850セッションを記録**いたしました。
2. **大都市圏（東京都・大阪府・愛知県・神奈川県）が全体の約65%**:
   * 長野県内（35.3%）の閲覧に加え、**東京都（26.6%）をはじめとする首都圏・関西圏・中京圏からのアクセスが約65%**を占めています。
3. **高い記事精読率（平均滞在時間 2分24秒 / モーダル閲覧1,200回超）**:
   * 平均滞在時間は2分24秒を記録し、個別記事・品種の詳細モーダル閲覧数は累計1,241回に達しています。
