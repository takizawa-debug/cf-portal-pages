# 飯綱町りんご料理レシピ データベース（全22品）

本フォルダは、飯綱町のりんごおよびクッキングアップル「ブラムリー」を活用した公式料理レシピブックのPDFから、オリジナルの高解像度画像と整形済みテキスト（材料・手順・ポイント）を抽出した正本データ集です。

## フォルダ構成
- `recipes_all.json` : 全レシピの完全メタデータ、材料リスト、手順、画像リンクを含む構造化JSON（API/CMS投入用）
- `markdown/` : レシピごとの個別Markdown記事（Frontmatter付き、そのまま静的サイトやCMS記事として利用可能）
- `images/original_jpg/` : PDFから直接抽出したオリジナル写真（文字被りなし、最高画質JPEG）
- `images/webp/` : Webサイト表示に最適化された軽量高画質WebP画像
